# 🌾 AI-Based Weed Detection System

## 📌 Overview
A deep learning-based web application that detects weeds and crops using image classification.

## 🧠 Model
- MobileNetV2 (Transfer Learning)

## ⚙️ Tech Stack
- Python
- TensorFlow / Keras
- Flask

## 🚀 Features
- Image upload
- Real-time prediction
- Confidence score

## ▶️ Run Project
pip install -r requirements.txt
python app.py
